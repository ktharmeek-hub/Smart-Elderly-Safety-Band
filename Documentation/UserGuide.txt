# Smart Elderly Safety Band

An IoT-based wearable emergency monitoring system designed to improve elderly safety through fall detection, inactivity monitoring, panic alerts, and caregiver notification.

## Overview

The Smart Elderly Safety Band is a wearable device that monitors elderly users and provides emergency assistance when abnormal situations are detected.

The system combines an ESP32-C3 wearable device with a Flutter mobile application. The wearable device performs local detection and provides immediate alerts using a buzzer, LEDs, and OLED display, while the mobile application receives notifications through Bluetooth Low Energy (BLE).

## Features

### Fall Detection
- Detects fall-like motion patterns using MPU6050 motion sensing.
- Analyzes acceleration changes and sudden impact.
- Provides warning and emergency alerts.

### Panic Alert
- Allows the user to manually trigger an emergency alert using a panic button.
- Useful when the user needs immediate assistance.

### Inactivity Detection
- Monitors user movement.
- Generates an alert when no significant movement is detected for a defined period.

### Sleep Mode
- Allows the user to enable sleep mode during rest.
- Prevents false inactivity alerts while maintaining emergency monitoring features.

### Alert Cancellation
- Allows users to cancel false alerts before escalation.

### Mobile Application
- Flutter-based caregiver application.
- Receives device notifications through Bluetooth Low Energy.
- Displays device status and alerts.

## Emergency Detection Flow

### Normal Mode
- Device continuously monitors motion and buttons.

### Warning Mode
When an abnormal event is detected:
- Red LED activates.
- Buzzer provides warning.
- OLED displays warning status.
- Mobile app receives notification.

### Emergency Mode
If the warning is not cancelled:
- Continuous alert is activated.
- Emergency notification is sent.

## LED Indicators

| LED | Status |
|---|---|
| Green | Normal monitoring |
| Blue | Sleep mode |
| Red | Warning / Emergency |

## Limitations

- BLE communication has a limited range.
- MPU6050 cannot directly measure exact fall height.
- Fall detection depends on acceleration and motion patterns.
- Battery percentage requires voltage measurement hardware for accurate estimation.

## Future Improvements

- Long-distance communication using Wi-Fi/GSM.
- GPS location sharing.
- Cloud-based caregiver monitoring.
- Improved fall detection using machine learning.
- Custom PCB design.
- Accurate battery monitoring using ADC measurement.

## Project Purpose

The purpose of this project is to develop a low-cost wearable safety system that can assist elderly users by detecting emergency situations and providing quick alerts to nearby people and caregivers.
